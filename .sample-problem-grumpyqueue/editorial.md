**Problem Editorial for Grumpy Queue.**

This is a very simple problem that can be solved with three lines of code.

It requires the solver to count the number of adjacent inversions in a list of numbers.

This can be done very simply by iterating through the list and incrementing a count every time a decreasing pair is identified.

An inattentive reader may confuse this problem with counting the number of inversions, and well known, and more challenging problem.

The only data structure required is the list required to hold the numbers.

The complexity of the solution is O(n).
